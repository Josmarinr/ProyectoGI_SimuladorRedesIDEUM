### Instrucciones de Puntuacion (Para el investigador)

El SUS genera un puntaje entre 0 y 100 calculado asi:

1. Para preguntas impares (1, 3, 5, 7, 9): restar 1 a la respuesta.
2. Para preguntas pares (2, 4, 6, 8, 10): restar la respuesta de 5.
3. Sumar todos los valores convertidos y multiplicar por 2.5.

**Interpretacion del puntaje:**

| Puntaje | Nivel de Usabilidad | Grado |
|---------|---------------------|-------|
| 0 - 25  | Inaceptable | F |
| 25 - 39 | Bajo | D |
| 40 - 52 | Regular | C |
| 53 - 73 | Bueno | B |
| 74 - 85 | Excelente | A- |
| 86 - 100 | Mejor posible | A |

Referencia: Bangor, A., Kortum, P. T., & Miller, J. T. (2008).

## Anexo: Resumen del Flujo de Evaluacion

```
+-------------------+       +-------------------+       +-------------------+
|                   |       |                   |       |                   |
|   PRE-TEST        |       |   SESION CON      |       |   POST-TEST       |
|   (10 min)        | ----> |   EL SIMULADOR    | ----> |   + SUS           |
|                   |       |   (45-60 min)     |       |   (15 min)        |
| Conocimientos     |       |                   |       |                   |
| previos +         |       | El participante   |       | Conocimientos     |
| expectativas      |       | interactua con    |       | adquiridos +      |
|                   |       | discos en la      |       | satisfaccion +    |
|                   |       | mesa IDEUM        |       | usabilidad (SUS)  |
+-------------------+       +-------------------+       +-------------------+
```

**Duracion total estimada:** 70 a 85 minutos por participante.
